**Enunciado.** `lim_{(x,y)→(0,0)} (xy cos y)/(3x² + y²)`.

**Resposta.** O limite **não existe**.

**Isole a parte que importa.** Como `cos y → cos 0 = 1 ≠ 0` por continuidade, o comportamento é o mesmo de `xy/(3x² + y²)`. Mas não precisa nem separar — basta testar dois caminhos na expressão original.

- Sobre `y = 0`, com `x ≠ 0`:
  ```
  f(x, 0) = 0·cos 0/(3x²) = 0 → 0
  ```
- Sobre `y = x`, com `x ≠ 0`:
  ```
  f(x, x) = (x² cos x)/(3x² + x²) = (x² cos x)/(4x²) = cos(x)/4 → 1/4
  ```

Como `0 ≠ 1/4`, o limite não existe pelo critério dos caminhos. ∎

**Vale conferir o padrão.** Sobre a reta genérica `y = mx`:

```
f(x, mx) = (m x² cos(mx))/((3 + m²)x²) = m cos(mx)/(3 + m²) → m/(3 + m²)
```

O valor **depende de m** — já bastaria isso para concluir. Repare que `m = 0` dá `0` e `m = 1` dá `1/4`, coerente com o que calculamos.

**Compare com o #16.** Lá o numerador tinha `x²·sen²y` (grau total 4) contra denominador de grau 2, e sobrava fator indo a zero. Aqui numerador e denominador têm o **mesmo grau 2**, o `x²` cancela e sobra uma constante que depende da direção. Comparar os graus é o primeiro diagnóstico a fazer.
