**Enunciado.** `lim_{(x,y)→(0,0)} (x² sen²y)/(x² + 2y²)`.

**Resposta.** O limite **existe e vale 0**.

**Separe em limitada × infinitésimo.** Escreva

```
(x² sen²y)/(x² + 2y²)  =  sen²y · [ x²/(x² + 2y²) ]
```

O fator entre colchetes é **limitado**: como `x² ≤ x² + 2y²` e ambos são `≥ 0`,

```
0 ≤ x²/(x² + 2y²) ≤ 1
```

E `sen²y → 0` quando `y → 0`, por continuidade do seno. Logo

```
0 ≤ (x² sen²y)/(x² + 2y²) ≤ sen²y → 0
```

e o confronto dá `0`. ∎

**Alternativa, se preferir majorar tudo.** Use `|sen y| ≤ |y|`, válida para todo `y` real:

```
(x² sen²y)/(x² + 2y²) ≤ (x² y²)/(x² + 2y²) ≤ y² → 0
```

**O padrão que vale guardar.** Sempre que der para escrever a expressão como **(algo que tende a zero) × (algo limitado)**, o limite é zero e a prova cabe em três linhas. Procure esse formato antes de tentar caminhos ou polares.

**Armadilha.** Trocar `sen²y` por `y²` sem justificar. A desigualdade `|sen y| ≤ |y|` precisa ser citada — ela é um resultado, não uma simplificação óbvia.
