# Fase 4 — Busca (RAG) nova: Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Um índice de busca por matéria, derivado do banco e dos arquivos, sempre sincronizado (inclui remoção do que foi apagado), com livros indexados por seção, filtros exatos por unidade/seção/tipo e leitura da seção completa — base do leitor de documentos (Fase 5) e do agente (Fase 6).

**Architecture:** O índice mora num arquivo separado, `<matéria>/.indice/indice.db` (fora do Git: é 100% derivável). Ele guarda **trechos** (pedaços de texto com origem, seção e página) e uma tabela FTS5 sobre eles. Cada origem (`fonte:N`, `documento:N`) tem uma **assinatura**; `sincronizar` compara assinaturas com o banco da matéria e só reindexa o que mudou, apagando trechos de origens que não existem mais. A busca anexa o `materia.db` (somente leitura) para filtrar por unidade **no momento da consulta**, então mudar o vínculo de um tópico não deixa o índice desatualizado.

**Tech Stack:** SQLite FTS5 (`unicode61 remove_diacritics 2`), PyMuPDF (via `importacao.pdf`), FastAPI.

**Spec:** `docs/superpowers/specs/2026-10-20-refatoracao-plataforma-design.md` §8 (RAG). A Task 6 emenda a spec: índice em arquivo próprio e unidade resolvida na consulta.

## Global Constraints

- O índice é **derivável**: apagar `.indice/` e sincronizar de novo dá o mesmo resultado. Nada do domínio depende dele.
- `sincronizar` sem mudanças não abre nenhum PDF (só compara assinaturas).
- Trecho nunca corta parágrafo, exceto parágrafo maior que o limite (corte na fronteira de frase mais próxima).
- O `rag.db` do app legado não é tocado.
- Mesmas convenções (português, `snake_case`, TDD, `.venv/Scripts/python -m pytest`).

## Review Focus

1. **Apagar um resumo ou uma fonte** → seus trechos somem da busca na próxima sincronização. Teste na Task 3.
2. **Mudar o vínculo tópico↔seção** (a seção passa a ser da unidade 2) → o filtro por unidade reflete na hora, sem reindexar. Teste na Task 4.
3. **Consulta com aspas, `*`, parênteses, `AND`/`OR`/`NEAR` ou só pontuação** → nunca erro de sintaxe do FTS5. Teste na Task 4.
4. **Índice de versão antiga ou corrompido** → é recriado sozinho. Teste na Task 1.
5. **Livro sem seções** (Stewart vol. 1, Leithold escaneado) → indexado por página ou ignorado com aviso, sem quebrar a sincronização. Teste na Task 3.

### Task 3: Indexador e sincronização

**Files:** Create `estudos/rag/indexador.py`, `tests/test_rag_indexador.py`

**Interfaces:**
```python
@dataclass class ResumoSincronizacao: indexadas: int; removidas: int; trechos: int; avisos: list[str]; tempo_ms: int
def assinatura_fonte(con_materia, fonte_id: int) -> str        # sha256 + tipo + (para livro) hash das seções (código, ini, fim)
def assinatura_documento(con_materia, documento_id: int) -> str  # caminho + atualizado_em
def sincronizar(con_materia, raiz: Path, caminho_indice: Path | None = None) -> ResumoSincronizacao
def indexar_fonte(indice, con_materia, raiz: Path, fonte_id: int) -> int      # devolve nº de trechos
```
Regras de indexação:
- **Livro com seções:** um conjunto de trechos por seção (`dividir_paginas` das páginas `ini..fim`, título `"<código> <título da seção>"`, `secao_id`); faixa do gabarito → trechos `tipo='gabarito'`; demais páginas (capa, prefácio) não entram.
- **Livro sem seções:** `dividir_paginas` do livro inteiro, `tipo='livro'`, sem seção. PDF sem texto → nenhum trecho + aviso.
- **Lista/prova/slides/anotação/outro/programa/calendário/turma:** `dividir_paginas`, `tipo = fonte.tipo`.
- **Documento:** `dividir_markdown`, `tipo = documento.tipo`, `secao_id = documento.secao_id`.
- Origem que sumiu do banco (fonte ou documento apagado) → trechos e estado removidos. Arquivo que não existe mais em disco → aviso, origem removida do índice.

- [ ] Testes (matéria com PDF sintético de 6 páginas como livro com 2 seções e gabarito, uma lista sintética e 2 documentos): 1ª sincronização indexa tudo; 2ª não reindexa nada (`indexadas == 0`) e não abre PDF (monkeypatch em `abrir_pdf` que falha); editar um documento → só ele reindexado; apagar documento → trechos somem (Review Focus 1); livro sem seções → por página; livro sem texto → aviso, sem erro (Review Focus 5); seções mudadas → livro reindexado → RED → implementar → GREEN → commit.

| GET | `/api/materias/{uid}/busca?q=&unidade=&secao_id=&tipo=&limite=` | `{"resultados": [Resultado], "sincronizacao": ResumoSincronizacao}` (sincroniza antes de buscar) |
