**Enunciado.** `lim_{(x,y)→(0,0)} xy⁴/(x² + y⁸)`.

**Resposta.** O limite **não existe** — e este é o exercício mais instrutivo da lista.

**Por que as retas enganam.** Sobre `y = mx`, com `x ≠ 0`:

```
f(x, mx) = x·m⁴x⁴/(x² + m⁸x⁸) = m⁴x⁵/(x²(1 + m⁸x⁶)) = m⁴x³/(1 + m⁸x⁶) → 0
```

E sobre `x = 0` também dá `0`. **Toda reta pela origem dá zero.** Se você parasse aqui e escrevesse "logo o limite é 0", estaria errado.

**O caminho que entrega.** Repare nos expoentes: o denominador tem `x²` e `y⁸`, então os dois termos ficam da mesma ordem quando `x` é da ordem de `y⁴`. Tome a curva `x = y⁴`, que passa pela origem:

```
f(y⁴, y) = y⁴·y⁴/((y⁴)² + y⁸) = y⁸/(y⁸ + y⁸) = 1/2
```

constante igual a `1/2` para todo `y ≠ 0`.

Como o limite sobre as retas é `0` e sobre `x = y⁴` é `1/2`, pelo critério dos caminhos o limite **não existe**. ∎

**Como se acha esse caminho — o método, não a sorte.** Olhe os graus do denominador e escolha a curva que **equilibra** os dois termos. Aqui: `x² ~ y⁸ ⟺ x ~ y⁴`. A mesma receita resolve o clássico `x²y/(x⁴+y²)` (equilibra com `y = x²`) e o `xy³/(x²+y⁶)` (com `x = y³`).

**A lição.** Caminhos servem para **negar**, nunca para afirmar. Concordância entre todas as retas não é prova de nada — para afirmar que o limite existe, é confronto ou polares.
