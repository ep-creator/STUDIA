**Enunciado.** Determine e esboce o domínio de `f(x,y) = arcsen(x² + y² − 2)`.

**Resposta.** O arco-seno só aceita argumento em `[−1, 1]`:

```
−1 ≤ x² + y² − 2 ≤ 1
⟺  1 ≤ x² + y² ≤ 3
```

```
D_f = { (x,y) ∈ ℝ² : 1 ≤ x² + y² ≤ 3 }
```

É a **coroa circular fechada** de raio interno `1` e raio externo `√3`, centrada na origem. As **duas** circunferências de bordo **pertencem** ao domínio — a desigualdade é `≤` dos dois lados —, então no esboço elas vão com linha **cheia** e a região entre elas hachurada.

**Imagem.** Como `x² + y² − 2` percorre todo o `[−1, 1]` dentro do domínio, `Im f = [−π/2, π/2]`.

**Armadilha.** Resolver só a metade da desigualdade. `arcsen` tem restrição dos **dois** lados, e é o lado `−1 ≤ …` que produz o buraco no meio. Se você achou um disco em vez de uma coroa, foi isso.
