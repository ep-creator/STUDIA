**Enunciado.** `lim_{(x,y)→(0,0)} xy/√(x² + y²)`.

**Resposta.** O limite **existe e vale 0**.

**Pelo teorema do confronto.** Para `(x,y) ≠ (0,0)`:

```
| xy/√(x²+y²) − 0 |  =  |x| · |y|/√(x²+y²)
```

Como `|y| ≤ √(x² + y²)`, o segundo fator é **limitado por 1**:

```
|y|/√(x²+y²) ≤ 1
```

Logo

```
0 ≤ | xy/√(x²+y²) |  ≤  |x|
```

e `|x| → 0` quando `(x,y) → (0,0)`. Pelo teorema do confronto, o limite é `0`. ∎

**Alternativa em polares.** Com `x = r cos θ`, `y = r sen θ`:

```
xy/√(x²+y²) = (r² cos θ sen θ)/r = r cos θ sen θ
```

e `|r cos θ sen θ| ≤ r → 0⁺`, **majoração independente de θ** — que é a condição para poder concluir. Vale `0`.

**Compare com o #12.** Lá o denominador era `x² + y²` (grau 2, igual ao numerador) e o `r` cancelava, deixando algo que dependia só de θ. Aqui o denominador é `√(x²+y²)` (grau 1), então sobra um `r` que força tudo a zero. **O que decide é o grau**: numerador de grau maior que o denominador ⇒ o limite tende a existir e valer 0.
