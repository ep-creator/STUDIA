**Enunciado.** Utilize **coordenadas polares** para determinar `lim_{(x,y)→(0,0)} (x³ + y³)/(x² + y²)`.

**Resposta.** O limite **existe e vale 0**.

**Substituição.** Com `x = r cos θ`, `y = r sen θ` e `r ≥ 0`, temos `x² + y² = r²`, e `(x,y) → (0,0)` equivale a `r → 0⁺`:

```
(x³ + y³)/(x² + y²) = (r³cos³θ + r³sen³θ)/r² = r (cos³θ + sen³θ)
```

**Majoração independente de θ** — é este passo que autoriza a conclusão:

```
| r (cos³θ + sen³θ) |  ≤  r ( |cos θ|³ + |sen θ|³ )  ≤  2r
```

Como `2r → 0` quando `r → 0⁺`, e a cota `2r` **não depende de θ**, o limite existe e vale `0`. ∎

**A condição que não pode faltar.** Passar para polares e ver que a expressão tende a zero "para cada θ fixo" **não prova nada** — isso é apenas percorrer os raios, ou seja, os caminhos retos. Só se pode concluir quando existe uma função `h(r)` com

```
| f(r cos θ, r sen θ) − L | ≤ h(r)   para todo θ,  e  h(r) → 0
```

Aqui `h(r) = 2r`. Escreva essa desigualdade explicitamente na prova; é o passo que o professor procura.

**Contraexemplo para fixar.** Em `2x²y/(x⁴+y²)`, as polares dão `2r³cos²θ senθ/(r⁴cos⁴θ + r²sen²θ)`, e não existe cota em `r` que sirva para todo θ — de fato o limite não existe (vale `1` sobre `y = x²`).
