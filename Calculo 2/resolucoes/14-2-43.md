**Enunciado.** Trace o gráfico e analise a continuidade de

```
f(x,y) = sen(xy)/(xy)   se xy ≠ 0
f(x,y) = 1              se xy = 0
```

**Resposta.** `f` é **contínua em todo o ℝ²**.

**A ideia: reconheça a composição.** Defina a função de uma variável

```
g(t) = sen(t)/t   se t ≠ 0
g(0) = 1
```

Essa `g` é **contínua em ℝ**: nos pontos `t ≠ 0` é quociente de contínuas com denominador não nulo, e em `t = 0` vale o limite fundamental `lim_{t→0} sen(t)/t = 1 = g(0)`.

Agora observe que, com `h(x,y) = xy`,

```
f(x,y) = g(h(x,y))    para todo (x,y)
```

— inclusive quando `xy = 0`, pois aí `g(0) = 1 = f(x,y)`. É a **definição por partes escrita como composição**, e isso é o coração da questão.

**Conclusão pelo teorema da composição.** `h(x,y) = xy` é polinomial, logo contínua em ℝ². `g` é contínua em ℝ, em particular em `h(x,y)` para todo `(x,y)`. Pelo teorema da composta, `f = g ∘ h` é contínua em todo ponto de ℝ². ∎

**O gráfico.** Como `f` depende apenas do produto `xy`, as **curvas de nível são hipérboles** `xy = c` (mais os eixos, onde `f = 1`). A superfície tem uma "crista" de altura 1 ao longo dos dois eixos, e oscila com amplitude decrescente conforme `|xy|` cresce — as ondulações se afastam ao longo das hipérboles. Não há rasgo nem salto em lugar nenhum, o que é a leitura visual da continuidade.

**Armadilha.** Tratar `xy = 0` como "só a origem". O conjunto `xy = 0` são os **dois eixos inteiros** — infinitos pontos onde a primeira fórmula não vale. Verificar a continuidade só em `(0,0)` deixa o problema pela metade; a composição resolve todos de uma vez.
