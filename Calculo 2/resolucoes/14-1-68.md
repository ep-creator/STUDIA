**Enunciado.** Descreva as superfícies de nível de `f(x,y,z) = x² − y² − z²`.

**Resposta.** A superfície de nível `k` é o conjunto

```
x² − y² − z² = k
```

Três casos, e o sinal de `k` decide qual:

| `k` | superfície | como é |
|---|---|---|
| `k > 0` | **hiperboloide de duas folhas** | duas conchas separadas, abrindo ao longo do eixo **x**, com vértices em `(±√k, 0, 0)` |
| `k = 0` | **cone** `x² = y² + z²` | duplo cone de eixo x, vértice na origem — é a superfície de transição |
| `k < 0` | **hiperboloide de uma folha** | uma peça só, tipo ampulheta aberta, envolvendo o eixo **x**, com “cintura” de raio `√(−k)` no plano `x = 0` |

**Por que o eixo x.** A variável com sinal **positivo** manda: é o eixo em torno do qual a superfície tem simetria de revolução. Aqui só `x²` é positivo, então tudo gira em torno do eixo x — e o cone de nível 0 é `x² = y² + z²`.

**Como verificar rápido, com traços.**

- Corte em `x = a`: `y² + z² = a² − k`, uma **circunferência** de raio `√(a² − k)` — existe só quando `a² ≥ k`. Se `k > 0`, não há corte para `|a| < √k`: é exatamente o buraco entre as duas folhas.
- Corte em `y = 0`: `x² − z² = k`, uma hipérbole no plano `xz` (par de retas quando `k = 0`).

**O que dá ponto na prova.** Não basta escrever "hiperboloide": diga **de quantas folhas**, **em torno de qual eixo**, e mostre o caso `k = 0` separando os dois regimes. É a mesma família do exercício 66 — só que lá os três sinais eram iguais e as superfícies eram elipsoides.
